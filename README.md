# JavaScript Data Types

## Primitive (Pass by Value)
- Number: `let num = 100;`
- String: `"Hello"`, `'JS'`, `` `ES6` ``
- Boolean: `true/false`
- Null: `null`
- Undefined: `let x;`
- Symbol: `Symbol('key')`
- BigInt: `123n`

## Non-Primitive (Pass by Reference)
- Array: `[1,2,3]`
- Object: `{name: "John"}`
- Function: `function(){}`
