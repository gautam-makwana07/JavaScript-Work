# JavaScript Practice Project

This repository contains a collection of JavaScript practice exercises and examples to help learn and reinforce fundamental concepts in JavaScript.

## Overview

The project includes various JavaScript files covering different topics such as data types, operators, control structures, loops, functions, arrays, and objects. It also features a practice file with common coding questions and their solutions using array methods.

## Files Included

- `index.html`: Basic HTML file to run JavaScript in the browser. Currently includes `objects.js`.
- `datatype.js`: Exercises on JavaScript data types.
- `operator.js`: Examples of JavaScript operators.
- `controllers.js`: Control structures (if-else, switch).
- `loops.js`: Looping constructs (for, while, etc.).
- `function.js`: Function declarations and usage.
- `array.js`: Array manipulation and methods.
- `objects.js`: Object creation and properties.
- `script.js`: General JavaScript scripts.
- `Javascript-Practics.js`: Practice questions with solutions using array methods like map, filter, some, every, find, and reduce.

## How to Run

1. Clone or download the repository.
2. Open `index.html` in a web browser to execute the included JavaScript files.
3. Alternatively, open any `.js` file in a JavaScript environment (browser console, Node.js) to run the code.

## Topics Covered

- Basic data types (strings, numbers, booleans)
- Arithmetic and comparison operators
- Conditional statements and loops
- Function definitions and calls
- Array methods and manipulation
- Object creation and property access
- ES6 features like destructuring and spread operator

## Examples

Here are some examples from the practice file:

```javascript
// Increase all prices by 10
const prices = [100, 200, 300];
const result = prices.map(p => p + 10);

// Filter even numbers
const numbers = [1, 2, 3, 4, 5, 6];
const evens = numbers.filter(n => n % 2 === 0);

// Calculate total bill amount
const bills = [120, 300, 80];
const total = bills.reduce((sum, b) => sum + b, 0);
```
